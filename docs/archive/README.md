# Archivo histórico

Los documentos de este directorio describen diseños y planes ya ejecutados o
reemplazados. Se conservan para consultar decisiones pasadas, pero sus rutas, nombres y
ejemplos pueden no coincidir con el código actual.

Para entender la arquitectura vigente, comenzar en el `README.md` de la raíz. Para el
estado actual de IA, consultar `docs/ai-core-pendientes.md`.
